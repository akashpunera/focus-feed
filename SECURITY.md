# Security

Focus Feed is an experimental Safari extension. Public source builds are intended for local evaluation. They use an ad-hoc signature and have not been notarized for managed deployment.

Focus Feed stores voted-on URLs, post text and reasons in local Safari extension storage. Its in-page confirmation and review UI shares a DOM with the host site. Avoid entering confidential notes. Per-vote deletion is available in the toolbar popup.

Use GitHub’s **Report a vulnerability** option if available. For other security concerns, open an issue describing the affected feature and risk without posting sensitive data or operational exploit details.
